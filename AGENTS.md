# inventory-pro — contributor and AI agent instructions

Before changing this project, read `DEVELOPMENT_PROCESS.md` and follow its
six-stage programming process and Figma UI/UX requirement.

Also inspect this repository's existing README, `CLAUDE.md` (if present),
architecture, security, testing, deployment and decision documents. Those
project-specific restrictions take precedence; this shared workflow does
not authorize production deployments, credential access, data migrations,
external purchases or irreversible changes.

For UI changes, inspect the **approved project-specific Figma userflow and
design file**, map screens to real product capabilities, and verify the
implemented visual behavior. If no design is approved or Figma is inaccessible,
do not invent a final design; record the blocker and continue safe work.

Report progress to the owner in plain language. Keep technical implementation
notes, test evidence and risks in repository Markdown and pull-request records.
